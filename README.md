# erkend-energielabel.github.io

Inloghulp voor Firebase op dit domein. De twee pagina's in `__/auth/` laden de
inlogcode van het Firebase-project `gereedmelding-cv` en laten Microsoft-inloggen
werken voor de apps op `erkend-energielabel.github.io`, ook in browsers die
cookies van derden blokkeren.

Niet verwijderen: zonder deze bestanden werkt Microsoft-inloggen in
Plannen met Jaap niet meer.
